# Security

## Reporting a vulnerability

Report it privately with **Report a vulnerability** on [this repository's Security tab](https://github.com/randyesperben/postmaster-of-puppets/security/advisories/new), or write to hey@postmasterofpuppets.com. Please do not open a public issue for it.

These count:

- A crafted DNS answer or record that makes the engine hang, crash, or take far more time or memory than a normal check.
- A verdict that says a domain is protected when anyone can send email as it.

Problems with postmasterofpuppets.com itself go to the same address.

## Supported versions

Fixes go to `main` and the next release.
